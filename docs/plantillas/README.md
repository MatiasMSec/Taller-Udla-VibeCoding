# Plantillas — bootstrap Vibe Coding

Copia esta estructura al **inicio de un proyecto nuevo** y reemplaza los marcadores `{{…}}`.

## Pasos

1. Copiar `docs/seguridad/` completo (directivas organizacionales, sin cambiar).
2. Copiar archivos de `docs/plantillas/contenido/` → `docs/arquitectura/` y `docs/funcional/`.
3. Editar `docs/README.md` (metadatos del proyecto).
4. Instalar regla `.cursor/rules/documentacion-vibe-coding.mdc` desde la raíz de este repo.

## Marcadores estándar

| Marcador | Significado |
| --- | --- |
| `{{PROJECT_NAME}}` | Nombre del producto |
| `{{ONE_LINE_PURPOSE}}` | Frase de propósito |
| `{{LAST_REVIEWED}}` | Fecha ISO |
| `{{TODO}}` | Pendiente de completar por agente/humano |
